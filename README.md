# 爆单 · 达人带货技能库

给抖音带货达人用的 AI 技能包。装进你的 AI 编程工具里，让它按你们的说话方式写口播稿。

> 为什么叫爆单：达人每天盯的就是这两个字。工具名不用解释，一眼知道是干什么的。

## 里面有什么

| 技能 | 干什么 |
|---|---|
| [daihuo-koubo](./skills/daihuo-koubo/SKILL.md) | 把产品卖点或对标文案，写成能直接念的带货口播稿 |

还会陆续加：选品、改对标、直播切片。没做出来之前不先占位，免得点进去是空的。

## 怎么装

任意支持 `SKILL.md` 的 agent 工具都能用（Claude Code、Codex、WorkBuddy 等）。

**方式一：整目录拷进去**

```bash
git clone https://github.com/suixiaozhang/baodanla.git
cp -r baodanla/skills/* ~/.你的工具/skills/
```

**方式二：只拷你要的那个**

```bash
git clone https://github.com/suixiaozhang/baodanla.git
cp -r baodanla/skills/daihuo-koubo ~/.你的工具/skills/
```

装完在工具里说「用 daihuo-koubo 写一条口播」，或者直接给它一个产品让它写，它会自己匹配。

## 它跟你平时见到的写作提示词有什么不一样

大部分写作提示词在教 AI「怎么写得好」，这个在教它「别怎么写」。

具体到这几条：

- 第一句必须是判断，不许铺垫
- 论点型稿件不许用「第一第二第三」
- 不许出现「定位路径」「选品逻辑」这类课件词
- 不许用收房租、开卷考、擂台这种花哨比喻
- 单量佣金数字沿用原稿，不许自己编
- 写得太顺、太工整，要故意拆碎

这些规则都是从真实口播里反推出来的，不是凭空设计的文风偏好。

## 为什么这些规则是硬的

口播稿只有一个验收标准：**念出来像不像人说的话**。

像人话的稿子，念着有停顿、有重复、有自己接自己话的地方。写得太漂亮的稿子，念出来一眼假，观众三秒就划走。

所以规则不追求文采，追求「不像稿子」。
